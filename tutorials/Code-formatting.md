#  ANSI-цвета, блочные символы и методики ввода в C++

## 🎨 1. ANSI-цвета для консоли

ANSI-последовательности — спецкоды терминала. Формат: `\033[<код>m`, где `\033` — ESC (`\x1b`, `\e`).

### 256 цветов

| Назначение | Формат с кодом |
|------------|----------------|
| Цвет текста (n = 0…255) | `\033[38;5;<n>m` |
| Цвет фона (n = 0…255) | `\033[48;5;<n>m` |

### TrueColor (16 млн цветов)

| Назначение | Формат с кодом |
|------------|----------------|
| Цвет текста | `\033[38;2;<R>;<G>;<B>m` |
| Цвет фона | `\033[48;2;<R>;<G>;<B>m` |

### ✅ Готовый пример (копировать целиком)

```cpp
#include <iostream>
using namespace std;

#define RESET   "\033[0m"
#define RED     "\033[31m"
#define GREEN   "\033[32m"
#define YELLOW  "\033[33m"
#define BLUE    "\033[34m"
#define BOLD    "\033[1m"
#define BG_BLUE "\033[44m"

int main() {
    cout << RED   << "Красный текст"    << RESET << endl;
    cout << GREEN << "Зелёный текст"    << RESET << endl;
    cout << BOLD << YELLOW << "Жирный жёлтый" << RESET << endl;
    cout << BG_BLUE << "Белый на синем" << RESET << endl;

    // 256 цветов
    cout << "\033[38;5;208mОранжевый\033[0m" << endl;

    // TrueColor
    cout << "\033[38;2;255;105;180mРозовый\033[0m" << endl;
    return 0;
}
```

### ✅ Готовый пример: включение ANSI в старом cmd.exe

```cpp
#include <windows.h>
```

## ⌨️ 3. Методики ввода данных

### 🔹 3.1 Оператор `>>`

```cpp
int n;
char ch;
cin >> n >> ch;
```
Читает до пробельного символа, ведущие пробелы пропускает.

### 🔹 3.2 `cin.getline()` — строка с пробелами

```cpp
char s[80];
cin.getline(s, 80);
```

### 🔹 3.3 `getline()` для `std::string`

```cpp
#include <string>
string s;
getline(cin, s);
```

### 🔹 3.4 `cin.get()` — посимвольный ввод

```cpp
char ch;
cin.get(ch);
cin.get();
```

### 🔹 3.5 `cin.ignore()` — пропуск символов

```cpp
cin.ignore();
cin.ignore(80, '\n');
```

### 🔹 3.6 `cin.width(n)` — ограничение длины

```cpp
char str[10];
cin.width(10);
cin >> str;
```

### 🔹 3.7 `ws` — пропуск ведущих пробелов

```cpp
#include <iomanip>
char s[80];
cin >> ws >> s;
```

### 🔹 3.8 `getline` с разделителем

```cpp
string s;
getline(cin, s, ';');
```

### ✅ Готовый пример: сброс `\n` после числа

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    cin.ignore();          // съесть '\n'

    string s;
    getline(cin, s);
    cout << "Число: " << n << ", строка: " << s << endl;
    return 0;
}
```

### ✅ Готовый пример: безопасный ввод числа

```cpp
#include <iostream>
using namespace std;

int readInt() {
    int x;
    while (!(cin >> x)) {
        cin.clear();
        cin.ignore(10000, '\n');
        cout << "Ошибка! Введите число: ";
    }
    return x;
}

int main() {
    cout << "Введите число: ";
    int n = readInt();
    cout << "Вы ввели: " << n << endl;
    return 0;
}
```

### ✅ Готовый пример: ввод до условия

```cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    while (cin >> x) {
        cout << x * 2 << endl;
    }
    return 0;
}
```

### ✅ Готовый пример: проверка успешности ввода

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    if (cin >> n) {
        cout << "OK: " << n << endl;
    } else {
        cout << "Ошибка ввода!" << endl;
        cin.clear();
        cin.ignore(1000, '\n');
    }
    return 0;
}
```

### Сводная таблица

| Задача | Инструмент |
|--------|-----------|
| Числа, слова без пробелов | `cin >> x` |
| Строка с пробелами (`char[]`) | `cin.getline(buf, N)` |
| Строка с пробелами (`string`) | `getline(cin, s)` |
| Один символ (включая `\n`) | `cin.get(ch)` |
| Пропустить `\n` после числа | `cin.ignore()` |
| Пропустить ведущие пробелы | `cin >> ws` |
| Ограничить длину ввода | `cin.width(N)` |
| Ввод до разделителя | `getline(cin, s, delim)` |
| Проверить ошибку | `if (!cin) { cin.clear(); cin.ignore(...); }` |

## 📌 Итоговые рекомендации

1. **Цвета:** используй `#define` для читаемости, всегда сбрасывай `\033[0m`.
2. **Блоки:** сохраняй `.cpp` в **UTF-8**, шрифт — **Consolas / Cascadia Mono**.
3. **Ввод:** помни про `\n` в буфере после `cin >>` — используй `cin.ignore()`.
4. **Строки с пробелами:** всегда `getline()`, а не `>>`.
5. **Проверяй ввод:** `if (!(cin >> x))` — залог стабильной программы.
